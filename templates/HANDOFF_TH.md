# ArtMath — บันทึกส่งต่องานแต่ละตอน

> แม่แบบว่างนี้เผยแพร่ได้ เมื่อกรอกบท ลิงก์สื่อ รายละเอียดเสียง หรือข้อมูลตอนแล้ว ให้เก็บสำเนาไว้ใน `.local/episodes/<episode>/HANDOFF_TH.md` และพื้นที่ส่วนตัวที่เลือก ห้าม commit สำเนาที่กรอกแล้วเข้า repository สาธารณะ
> ใช้ `not_run`, `passed`, `failed`, `blocked` ตามผลจริง ไม่ใช้ผลจากตอนหรือ commit เก่ามายืนยันงานใหม่
